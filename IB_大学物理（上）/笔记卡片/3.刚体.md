# 刚体的定轴转动

## 一、刚体的定轴转动

### 1. 刚体的定义
所谓刚体，就是在任何情况下，大小和形状都不会发生任何变化的物体。

### 2. 描述刚体的定轴转动的物理量

- **角速度大小**：$\omega = \frac{d\theta}{dt}$ (rad · s⁻¹)
- **线速度大小**：$v = \frac{ds}{dt} = r\omega$
- **角加速度大小**：$\alpha = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$
- **切向加速度**：$a_t = \frac{dv}{dt} = r\alpha$
- **法向加速度**：$a_n = r\omega^2$

## 二、刚体的定轴转动定律

### 1. 力矩
力矩 $\mathbf{M} = \mathbf{r} \times \mathbf{F}$

- 力矩的z分量 $M_z = rF_\perp = rF\sin\theta$
- 力对整个z轴上所有点的力矩的z分量相等，称这个力矩的z分量为力F相对于转轴（z轴）的力矩。

### 2. 刚体定轴转动定律
$M_z = J\alpha$

- 其中，J为刚体对转轴的转动惯量，$J = \sum m_ir_i^2$（质点系），或 $J = \int r^2 dm$（连续体）
- 转动惯量由刚体上各质元相对于固定转轴的分布决定，与外力无关，是由刚体本身性质决定的。

### 3. 刚体定轴转动定律的应用
在定轴转动中，刚体所受合外力对转轴的力矩等于刚体对该转轴的转动惯量和角加速度的乘积。

## 三、转动惯量的计算

### 1. 转动惯量的计算方法
- 构成刚体的质量元是分立的：$J = \sum m_ir_i^2$
- 刚体的质量是连续分布的：$J = \int r^2 dm$

### 2. 平行轴定理
若有任一轴与过质心的轴平行，相距为d，刚体对其转动惯量为J_A，则有：
$J_A = J_C + md^2$
其中，J_C是对通过质心的轴的转动惯量。

### 3. 垂直轴定理（正交轴定理）
对于薄平板状刚体，有：
$J_z = J_x + J_y$

### 4. 常见刚体的转动惯量
- 长为L、质量为m的均匀细棒：
  - 绕过A点的转轴的转动惯量：$J_A = \frac{1}{3}mL^2$
  - 绕过质心的转轴的转动惯量：$J_C = \frac{1}{12}mL^2$
- 半径为R的均匀圆环对与环面垂直的转轴的转动惯量：$J = MR^2$
- 半径为R的匀质薄圆盘对通过其中心且垂直于盘面的转轴的转动惯量：$J = \frac{1}{2}MR^2$
- 长度为L的匀质细杆对通过其中心且垂直于杆的转轴的转动惯量：$J = \frac{1}{12}mL^2$
- 长度为L的匀质细杆对通过其端点且垂直于杆的转轴的转动惯量：$J = \frac{1}{3}mL^2$
- 半径为R的实心圆柱体对通过其中心轴的转动惯量：$J = \frac{1}{2}MR^2$
- 半径为R的均匀球体对通过其中心的转轴的转动惯量：$J = \frac{2}{5}MR^2$

## 四、刚体定轴转动定律的应用示例

### 例1：两匀质直细杆的角加速度比较
已知两匀质直细杆，L > L'，质量均为m，分别绕过其端点的水平轴转动。求从小倾角θ处静止释放时的角加速度。

- 对于长为L的细杆：
  $J = \frac{1}{3}mL^2$
  $M = mg\frac{L}{2}\sin\theta$
  $\alpha = \frac{M}{J} = \frac{mg\frac{L}{2}\sin\theta}{\frac{1}{3}mL^2} = \frac{3g\sin\theta}{2L}$

- 对于长为L'的细杆：
  $J' = \frac{1}{3}mL'^2$
  $M' = mg\frac{L'}{2}\sin\theta$
  $\alpha' = \frac{M'}{J'} = \frac{3g\sin\theta}{2L'}$

由于L > L'，所以α' > α，即短杆的角加速度大，更难控制。

### 例2：圆轮上挂细绳，细绳两端各挂两物
在半径为R，质量为m的圆轮上挂一细绳，细绳两端各挂两物m₁和m₂（m₁ > m₂）。求两物的加速度a及轮子的角加速度β。

- 根据牛顿定律：
  $m_1g - T_1 = m_1a$
  $T_2 - m_2g = m_2a$

- 根据定轴转动定律：
  $T_1R - T_2R = J\beta$
  其中，J为圆轮的转动惯量，对于匀质圆盘，$J = \frac{1}{2}mR^2$
  又因为$a = R\beta$

联立以上方程，解得：
$a = \frac{(m_1 - m_2)g}{m + m_1 + m_2}$
$\beta = \frac{(m_1 - m_2)g}{R(m + m_1 + m_2)}$

### 例3：薄圆盘在粗糙水平桌面上的转动
一质量均匀分布的薄圆盘，半径为R，盘面与粗糙的水平桌面紧密接触。圆盘绕通过其中心的竖直轴线转动，开始时角速度为ω₀。已知圆盘与桌面间摩擦系数为μ₀，问经过多少时间后圆盘静止不动？

- 考虑面元ds对轴的摩擦力矩：
  $dM = r\mu_0gdm = r\mu_0g\frac{m}{\pi R^2}2\pi rdr = \frac{2\mu_0gm}{R^2}r^2dr$
  整个圆盘受到的力矩为：
  $M = \int_0^R \frac{2\mu_0gm}{R^2}r^2dr = \frac{2\mu_0gm}{R^2} \cdot \frac{R^3}{3} = \frac{2\mu_0gmR}{3}$

- 圆盘的转动惯量：
  $J = \frac{1}{2}mR^2$

- 根据转动定律：
  $M = J\beta$
  $\beta = \frac{M}{J} = \frac{\frac{2\mu_0gmR}{3}}{\frac{1}{2}mR^2} = \frac{4\mu_0g}{3R}$

由于摩擦力的力矩是恒定的，角速度均匀减小，直到静止。设经过时间t后圆盘静止，则：
$\omega(t) = \omega_0 + \beta t$
当ω(t) = 0时，
$t = -\frac{\omega_0}{\beta} = -\frac{\omega_0}{\frac{4\mu_0g}{3R}} = \frac{3R\omega_0}{4\mu_0g}$

## 五、答题范式

### 1. 分析受力情况
明确刚体所受的外力，确定哪些力对转轴有力矩。

### 2. 应用刚体定轴转动定律
根据$M_z = J\alpha$，结合转动惯量的计算和角加速度的求解。

### 3. 联立方程求解
当涉及多个物体时，需要联立牛顿定律和转动定律方程，解出未知量。

### 4. 注意单位和量纲
确保各物理量的单位一致，量纲正确。

### 5. 检查结果合理性
验证结果是否符合物理直觉，例如角加速度的方向是否合理，转动惯量的大小是否符合预期等。
