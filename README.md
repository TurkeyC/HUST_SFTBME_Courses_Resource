<summary><bold>如何成为本项目的Contributor</bold></summary>

我们非常欢迎你的贡献！如果你有任何改进建议或想要添加新的课程资料，请遵循以下步骤：

1.  **Fork 本仓库：** 点击页面右上角的 "Fork" 按钮，将本仓库复制到你自己的 GitHub 账户下。
2.  **创建你的分支：** 从 `main` 分支创建一个新的分支来进行你的修改。建议分支名能清晰描述你的修改内容，例如 `feature/add-calculus-notes` 或 `fix/typo-in-readme`。
    ```bash
    git checkout -b feature/YourAmazingFeature
    ```
3.  **进行修改：** 在你的本地仓库中添加或修改文件。
    *   如果是添加新的课程资料，请尽量按照现有的目录结构组织文件。
    *   如果资料包含多个文件，建议创建一个新的子文件夹。
    *   请确保你添加的资料不侵犯版权。
    *   **文件和文件夹命名规范建议：**
        *   **文件夹命名：** 对于新的课程，建议使用 `学期代码_课程名称` 的格式，例如 `IIA_模拟电子技术`。学期代码参照已有的命名方式（如 IA, IB）。
        *   **文件命名：** 文件名应清晰描述内容，例如 `[类型]_[内容描述].[后缀]`，如 `课件_第一章_绪论.pdf`，`笔记_期末复习重点.docx`，`作业_实验一报告.md`。避免使用过于随意或模糊的名称。
        *   统一使用下划线 `_` 作为单词分隔符，避免使用空格或特殊字符。
4.  **提交你的修改：** 将你的修改提交到你的本地分支。
    ```bash
    git add .
    git commit -m 'feat: 添加了xxx课程的相关资料'
    ```
    请使用清晰的提交信息，简要描述你的修改内容。可以参考 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/v1.0.0/) 规范(虽然我自己都没按照这个规范提交过)。
5.  **推送到你的分支：** 将你的本地分支推送到你 Fork 的远程仓库。
    ```bash
    git push origin feature/YourAmazingFeature
    ```
6.  **创建 Pull Request (PR)：** 回到本项目的 GitHub 页面，你会看到一个提示，可以从你推送的分支创建一个 Pull Request。点击该按钮，并填写 PR 的标题和描述，清楚地说明你的修改内容和原因。
7.  **等待审查：** 项目维护者会审查你的 PR。如果需要修改，我们会进行评论。修改完成后，你的 PR 将会被合并。

感谢你的贡献！
</details>
