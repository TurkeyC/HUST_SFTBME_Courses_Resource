🤝 贡献指南 ​

感谢您对H.S.B.C.R.项目的关注！我们非常欢迎您的贡献，无论是提交学习资料、报告问题还是提出改进建议。

为什么要贡献？ ​

  • 帮助同学：您的资料可能正是其他同学急需的学习材料
  • 知识共享：促进学术交流，营造良好的学习氛围
  • 个人成长：在分享过程中巩固自己的知识，提升表达能力
  • 开源精神：践行开源文化，为教育事业贡献力量

贡献类型 ​

学习资料贡献 ​

我们欢迎以下类型的学习资料：

  • 课程课件：老师授课的PPT、PDF等
  • 作业答案：课后习题解答、参考答案
  • 考试真题：期中、期末考试题目及解析
  • 实验资料：实验指导书、实验报告模板、代码
  • 学习笔记：个人整理的知识点、思维导图
  • 学习经验：学习方法、考试技巧、复习策略
  • 参考资料：推荐书籍、在线课程、学习工具

问题报告 ​

如果您发现以下问题，请及时报告：

  • 资料内容错误或过时
  • 文件损坏无法打开
  • 链接失效或无法访问
  • 分类错误或命名不规范
  • 网站功能异常

改进建议 ​

我们也欢迎您提出：

  • 新功能需求
  • 用户体验改进
  • 网站设计优化
  • 内容组织结构调整

如何贡献 ​

方法一：通过 GitHub（推荐） ​

这是最直接和高效的贡献方式，适合有一定 Git 基础的同学。

1️⃣ Fork 本仓库 ​

点击 GitHub 页面右上角的 "Fork" 按钮，将项目复制到您的 GitHub 账户下。

2️⃣ 克隆到本地 ​

bash
git clone https://github.com/你的用户名/HUST_SFTBME_Courses_Resource.git
cd HUST_SFTBME_Courses_Resource

3️⃣ 创建分支 ​

bash
git checkout -b feature/你的功能描述
# 例如：git checkout -b feature/add-physics-notes

4️⃣ 添加或修改文件 ​

按照 文件命名规范 整理您的资料。

5️⃣ 提交更改 ​

bash
git add .
git commit -m "feat: 添加了物理课程笔记"

提交信息建议遵循 约定式提交 规范：

  • feat: 新增功能或资料
  • fix: 修复错误
  • docs: 文档更新
  • style: 格式调整
  • refactor: 重构代码
  • test: 测试相关

6️⃣ 推送到远程分支 ​

bash
git push origin feature/你的功能描述

7️⃣ 创建 Pull Request ​

在 GitHub 上创建 Pull Request，详细描述您的更改内容。

方法二：通过 Issues ​

如果您不熟悉 Git 操作，可以通过 GitHub Issues 提交资料：

  1. 访问 Issues 页面
  2. 点击 "New Issue"
  3. 选择合适的模板或创建空白 Issue
  4. 详细描述您要贡献的内容
  5. 可以将文件上传到网盘并分享链接

方法三：联系维护者 ​

您也可以直接联系项目维护者：

  • GitHub: @TurkeyC

文件命名规范 ​

为了保持项目的整洁和一致性，请遵循以下命名规范：

文件夹命名 ​

学期代码_课程名称/

学期代码规则：

  • IA - 大一上学期
  • IB - 大一下学期
  • IIA - 大二上学期
  • IIB - 大二下学期
  • 以此类推...

示例：

IA_微积分A（上）/
IB_大学物理（上）/
IIA_模拟电子技术/

文件命名 ​

[类型]_[内容描述].[扩展名]

类型标识：

  • 课件 - 教学PPT、PDF等
  • 作业 - 练习题、作业题
  • 答案 - 作业答案、习题解答
  • 真题 - 考试真题
  • 解析 - 真题解析、答案详解
  • 笔记 - 学习笔记、总结
  • 实验 - 实验指导、实验报告
  • 教材 - 课本、参考书
  • 资料 - 其他相关资料

示例：

课件_第一章_函数与极限.pdf
作业_习题集_第三章.docx
答案_期中考试_2023年春.pdf
真题_期末考试_2022年秋.pdf
笔记_重点知识点整理.md
实验_单摆实验_指导书.pdf

命名注意事项 ​

避免使用：

  • 空格（用下划线 _ 代替）
  • 特殊字符（如 *, ?, :, <, >, | 等）
  • 中文标点符号（用英文标点代替）
  • 过长的文件名（建议不超过50个字符）

推荐做法：

  • 使用下划线 _ 分隔不同部分
  • 使用有意义的描述性名称
  • 保持命名的一致性
  • 添加版本号或年份信息

质量标准 ​

为了确保资料的质量和实用性，请确保您贡献的内容符合以下标准：

内容质量 ​

  • 准确性：确保内容无错误，信息准确可靠
  • 完整性：资料内容完整，没有缺失的重要部分
  • 清晰性：内容表述清楚，易于理解
  • 实用性：对学习确实有帮助，具有参考价值

文件质量 ​

  • 可读性：文件能够正常打开和阅读
  • 格式规范：使用常见的文件格式（PDF、DOC、MD等）
  • 大小合理：文件大小适中，便于下载和存储
  • 版权合规：确保不侵犯他人版权

组织结构 ​

  • 分类准确：放在正确的课程目录下
  • 命名规范：遵循项目的命名约定
  • 去重检查：避免上传重复的资料
  • 更新及时：保持资料的时效性

版权和法律 ​

版权说明 ​

  • 原创内容：您贡献的原创内容将采用 MIT 许可证
  • 第三方内容：请确保您有权分享第三方内容，或该内容属于公共领域
  • 学术用途：所有资料仅供学术学习使用，不得用于商业目的
  • 侵权处理：如发现版权问题，我们将及时处理

禁止内容 ​

请不要上传以下类型的内容：

  • 违反法律法规的内容
  • 侵犯他人版权的资料
  • 包含个人隐私信息的文件
  • 恶意软件或病毒文件
  • 与课程学习无关的内容
  • 考试作弊相关资料
