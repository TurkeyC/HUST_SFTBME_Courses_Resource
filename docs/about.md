# 关于项目

## 项目简介

**HUST SFTBME Courses Resource** 是TurkeyC受到GitHub上的相关仓库启发创建的课程资源共享平台，致力于收集、整理和分享学习资料。

### 资料类型

- **教学课件**：老师授课使用的PPT、PDF等教学材料
- **作业习题**：课后作业、练习题及参考答案
- **考试真题**：历年期中、期末考试真题及详细解析
- **实验资料**：实验指导书、实验报告模板、实验代码
- **学习笔记**：个人整理的知识点总结、思维导图
- **参考教材**：推荐使用的教材和参考书籍

## 项目特色

### 专业针对性

- 专门针对华中科技大学未来技术学院生医方向
- 贴合实际课程设置和教学安排
- 资料与最新课程内容同步更新

### 系统性整理

- 按学期和课程分类组织
- 统一的文件命名规范
- 清晰的目录结构设计

### 开源协作

- 采用 MIT 开源许可证
- 欢迎所有同学参与贡献
- 通过 GitHub 进行版本控制和协作

### 持续更新

- 跟随课程进度实时更新
- 定期补充新的学习资料
- 及时修正错误和过时内容

## 项目目标

### 短期目标

- **资料完善**：收集齐全大一两个学期的所有课程资料
- **质量提升**：确保所有资料的准确性和实用性
- **用户体验**：优化网站界面和使用体验
- **社区建设**：吸引更多同学参与贡献

### 长期目标

- **课程扩展**：逐步添加大二、大三、大四的课程资料
- **功能增强**：添加搜索、评论、评分等功能
- **移动适配**：优化移动端访问体验

### 2024年

- **10月**：项目启动，开始收集大一上学期资料
